# Проект по продаже авторских портретов

Приложение для продажи авторских портретов, разработанное на нативном JavaScript без использования фреймворков. Используется Gulp для сборки проекта.

## 🚀 Запуск проекта

1. Установите зависимости:

```bash
npm i
```

2. Запустите сборку и сервер разработки:

```bash
gulp
```

## 📁 Структура проекта

- `src/` — исходные файлы (HTML, SCSS, JS, изображения)
- `dist/` — результат сборки
- `gulpfile.js` — конфигурация Gulp
- `package.json` — зависимости проекта

## 🛠️ Используемые технологии

- HTML5, CSS3 (SCSS)
- JavaScript (ES6+)
- Gulp (автоматизация задач)

## 📷 Описание

Проект представляет собой лендинг или интернет-магазин, где пользователи могут заказать авторские портреты. Основной акцент сделан на производительность, чистый код и отсутствие внешних JS-фреймворков.
